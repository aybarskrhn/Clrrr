# ClearVault

**AI-powered M&A due diligence auditor.** Drop a PDF data-room document, get structured financials and severity-ranked red flags in under 90 seconds. Built for junior analysts at boutique investment banks and PE firms who can't afford enterprise AI tools — and can't risk leaking confidential deal data to public LLMs.

---

## Overview

| Layer | Stack |
|---|---|
| Frontend | React 19, React Router v7, Tailwind CSS, shadcn/ui (Radix UI), React Query |
| Backend | FastAPI, Motor (async MongoDB), PyJWT, bcrypt |
| AI | Gemini 2.5 Flash via `emergentintegrations` |
| Payments | Stripe Checkout via `emergentintegrations` |
| Storage | MongoDB Atlas + local filesystem for PDF uploads |

Design language: Bloomberg terminal — `#0A0A0A` background, amber (`#FF8C00`) accent, IBM Plex Mono for all data, zero shadows, 1 px borders.

---

## Features

- **JWT auth** — signup / login / `me` endpoint
- **Deals CRUD** — create, list, view, delete deals with live red-flag + document counts
- **PDF upload & AI extraction** — drag-and-drop upload triggers a background Gemini extraction: `financial_metrics`, `key_terms`, `red_flags`, `parties`, `confidence`
- **Dashboard** — KPI stats, deal book table, real-time activity ticker
- **Analysis terminal** — ask free-form questions across a deal's documents with cited page references and PDF highlights
- **CSV export** — one-click download of financials, red flags, and key terms
- **IC memo roll-up** — multi-document deal summary generated by AI
- **Public share links** — shareable read-only IC memo URLs with optional password and expiry
- **Slack notifications** — webhook alert when extraction completes
- **Organizations / teams** — invite members, assign admin/member roles, switch workspaces
- **Billing** — Stripe Checkout for Desk monthly/annual plans
- **Command palette** — `⌘K` search across deals, documents, and red flags

## Environment Variables

### Backend (`backend/.env`)

```env
MONGO_URL=mongodb://localhost:27017
DB_NAME=clearvault
JWT_SECRET=your-secret-here
GEMINI_API_KEY=your-gemini-key
STRIPE_API_KEY=sk_test_...
CORS_ORIGINS=http://localhost:3000
PUBLIC_APP_URL=http://localhost:3000   # used in Slack notification links
UPLOAD_DIR=/tmp/clearvault_uploads     # optional, defaults to /tmp/clearvault_uploads
```

### Frontend (`frontend/.env`)

```env
REACT_APP_API_URL=http://localhost:8001
```

## Running Locally

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8001 --reload
```

API available at `http://localhost:8001`. Interactive docs at `http://localhost:8001/docs`.

### Frontend

```bash
cd frontend
yarn install
yarn start
```

App available at `http://localhost:3000`.

## API Reference (key endpoints)

| Method | Path | Description |
|---|---|---|
| `POST` | `/api/auth/signup` | Register |
| `POST` | `/api/auth/login` | Login → JWT |
| `GET` | `/api/auth/me` | Current user |
| `GET` | `/api/dashboard/stats` | KPI counts |
| `GET` | `/api/deals` | List deals |
| `POST` | `/api/deals` | Create deal |
| `POST` | `/api/deals/:id/documents` | Upload PDF (triggers AI extraction) |
| `GET` | `/api/deals/:id/documents` | List documents |
| `GET` | `/api/documents/:id` | Document + extraction result |
| `GET` | `/api/deals/:id/export.csv` | Download CSV export |
| `POST` | `/api/deals/:id/rollup` | Generate IC memo roll-up |
| `POST` | `/api/deals/:id/share` | Create public share link |
| `POST` | `/api/analyze` | Ask a question across documents |
| `GET` | `/api/search?q=` | Global search |
| `GET` | `/api/orgs/current` | Current workspace + members |
| `POST` | `/api/orgs/current/invites` | Invite a team member |
